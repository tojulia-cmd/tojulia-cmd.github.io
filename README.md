# My secretary — публичные страницы

Информационный сайт личного Telegram-секретаря. Три статические страницы без сборки и зависимостей.

- `index.html` — описание приложения.
- `privacy.html` — обработка данных и внешние сервисы.
- `terms.html` — условия использования.
- `styles.css` — общие стили.

Публикация: GitHub Pages, ветка `main`, корень `/`. Ожидаемый адрес: https://tojulia-cmd.github.io/.

Рабочий бот находится на отдельном сервере и использует готовый код https://github.com/stavzzz/svyazka-1. Ключи, OAuth-реквизиты и состояние бота в этот репозиторий не добавляются.

Публикация сайта сама по себе не подтверждает принятие домена или OAuth-приложения Google.
